# Hail assets

Public images for [Hail](https://hail.itayp2405.workers.dev), served through the jsDelivr CDN:

`https://cdn.jsdelivr.net/gh/itay2405/hail-assets@v1/avatars/<name>.webp`

- `avatars/`: profile pictures (256×256 WebP). A new picture set gets a new tag (v2, …) so cached copies never go stale.
